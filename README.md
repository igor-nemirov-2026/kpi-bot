# KPI-бот для FMCG-дистрибуции: Excel → GitHub → Telegram

На компьютер ничего ставить не нужно. Всё считает GitHub.

**Когда приходит пост в Telegram**

- по кнопке: вкладка **Actions** → **KPI в Telegram** → **Run workflow**;
- сразу после загрузки нового Excel в папку `data`;
- по будням в 10:00 и 15:00 по Киеву.

**Что приходит в канал**

1. Сводка: ключевые цифры, светофоры по каждой роли, главные отклонения и нужный темп.
2. Альбом из 4 картинок — дашборды CFO, собственника, коммерции и закупок.
3. HTML-файл с полным дашбордом: вкладки по ролям, таблица всех KPI, графики.

## Запуск за 10 минут

1. **Бот.** В Telegram откройте @BotFather → `/newbot` → придумайте имя и username на `bot` → скопируйте токен.
2. **Канал.** Создайте канал (или группу) → добавьте бота администратором → отправьте в канал слово «тест».
3. **chat_id.** Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":-100…`.
4. **Репозиторий.** github.com → **New repository** → имя `kpi-bot` → **Create**. Затем **uploading an existing file** → перетащите все файлы и папки из этого архива → **Commit changes**.
5. **Секреты.** **Settings** → **Secrets and variables** → **Actions** → **New repository secret**: `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
6. **Запуск.** **Actions** → **KPI в Telegram** → **Run workflow**. Через 1–2 минуты пост будет в канале.

## Как обновить данные

Откройте `data/KPI_import_template.xlsx` у себя, внесите цифры и сохраните. Затем на GitHub: папка `data` → **Add file** → **Upload files** → перетащите файл с тем же именем → **Commit changes**. Пост придёт сам.

## Логика расчёта

- **План дня** = план месяца / рабочие дни (лист «Календарь»).
- **Выполнение** = факт / план; для показателей «чем меньше, тем лучше» — план / факт.
- **Прогноз месяца** — по текущему темпу.
- **Прогноз года** = факт + прогноз текущего месяца + планы оставшихся месяцев × выполнение с начала года.
- **Светофор:** ≥ 100% — зелёный, 95–100% — жёлтый, < 95% — красный.

Цифры в шаблоне демонстрационные: модель дистрибутора на 1000 сотрудников, 7,2 млн грн выручки на сотрудника.
